PLUME LOGO PACKAGE
==================

FILES
- plume-logo.svg            Main lockup (mark + wordmark) for light backgrounds
- plume-logo-reversed.svg   Lockup for dark backgrounds (includes Ink background)
- plume-mark.svg            Mark only: app icon, avatar, social profile
- plume-mark-mono.svg       One-color mark: stamps, print, favicon tests

COLORS
- Cloud       #FAF9F6  backgrounds
- Ink         #1B1B2F  text and UI
- Plume Coral #FF6B57  brand accent
- Sky         #7FB7FF  secondary
- Gold        #F2B84B  Pro / upgrade only

TYPE
- Headlines: Sora (Bold / ExtraBold), free on Google Fonts
- Interface and body: Inter, free on Google Fonts

USAGE NOTES
- Keep clear space around the logo equal to the height of the mark's corner bracket.
- Do not recolor the feather or stretch the logo.
- The wordmark in the lockup files is live text set in Sora. Convert it to
  outlines in a vector editor (Figma, Illustrator, Inkscape) before using the
  files as final artwork, so it renders the same everywhere.
- Run a trademark and domain check on the name before launch.
